# @knitjs/common

Shared decorators, types, and utilities for Knit applications.

## Installation

```bash
pnpm add @knitjs/common
```

## Exports

- **Decorators** — `@KnitController`, `@KnitParam`, and all NestJS decorators.
- **HTTP metadata** — Re-exported `@nestjs/common` symbols such as `@Get`, `@Post`, and `@Param`.
- **Types** — Route context, parsed route parameters, and core framework types.
